# Keep NovaPDF focused on a personal hosted lecture reader

The planned next release is a personal lecture-slide reader hosted on Vercel at an unlisted URL for convenient access, without login or document sharing. It retains reading, search, tutoring, and a plain PDF view with keyboard access to the extra tools; lecture PDFs for different subjects are in scope, while the SQL subsystem and OCR are excluded. This keeps the existing study workflow focused, with reliable setup, clear errors, and tested core workflows taking priority over a visual redesign; because there is no login, anyone who obtains the URL can access the app.

The current improvement pass is limited to modest code cleanup, performance improvements, and fixes to existing behavior.
